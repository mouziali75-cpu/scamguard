A free, protection-focused Android browser built around ScamGuard's detection engine — featuring real-time anti-scam and NSFW blocking, ad and tracker filtering, payment and download guards, and multilingual support (English, Arabic, French).

[![Download APK](https://img.shields.io/badge/Download-Ven%20APK%20(v1.2)-2EA44F?style=for-the-badge&logo=android&logoColor=white)](https://github.com/mouziali75-cpu/scamguard/releases/tag/ven-15)

---

## ✨ Features

- 🛡️ **Anti-scam & phishing protection** — detects suspicious domains, lookalike/brand impersonation, risky keywords, unsafe links, and dangerous page patterns with warning banners and block pages
- 🔞 **NSFW / adult content blocker** — filters adult sites, RTA-labeled pages, and enforces SafeSearch on supported search engines
- 🚫 **Ad, tracker & pop-up blocking** — blocks ad hosts, unwanted auto-redirects, pop-ups, and strips common tracking query parameters (`utm_`, `fbclid`, `gclid`, etc.)
- 💳 **Payment & download guards** — optional blocking for payment pages/card fields and all downloads, plus warnings for risky file extensions
- ⚙️ **Per-site controls & customization** — toggle protections per domain, switch desktop/mobile mode, use dark mode on web pages (Android 10+), and inspect page source (Raw / Rendered DOM)
- 🌐 **Multilingual interface (EN / AR / FR)** — full UI support with RTL layout for Arabic
- 👑 **Owner panel & live list updates** — refresh threat/ad lists on demand and manage owner configuration/icons

---

## 📥 Installation

1. Click the **Download APK** button above and download **Ven** (`app.ven.browser`, Android 8.0+ / API 26+)
2. Install the APK on your Android device (allow installing from unknown sources if prompted)
3. Open **Ven** and configure your preferred protection and language options in **Settings**
