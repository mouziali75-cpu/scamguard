# 🛡️ ScamGuard Lite

![Version](https://img.shields.io/badge/version-9.2-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Made with](https://img.shields.io/badge/made%20with-JavaScript-yellow)
[![YouTube Subscribers](https://img.shields.io/youtube/channel/subscribers/UCf_o8wg-WMn2O080LQA1CZg)](https://www.youtube.com/channel/UCf_o8wg-WMn2O080LQA1CZg)

A free, community-powered userscript that automatically detects phishing, scam, and adult content sites — with multilingual support (English, Arabic, French) and a built-in reporting system.

---

## ✨ Features

- 🛡️ Real-time phishing/scam detection (manual + online threat lists)
- 🔞 Adult content detection
- ⚠️ Unwanted/spam site detection
- 🚩 One-tap reporting system with Discord integration
- 🌐 Multilingual interface (EN / AR / FR)
- 🔐 Admin panel with Discord bot approval (Accept/Deny)

---

## 📥 Installation

1. Install [Via Browser](https://play.google.com/store/apps/details?id=mark.via.gp) (or any Tampermonkey-compatible browser)
2. Enable Scripts in the browser settings
3. Tap the button below to install the script:

[![Install ScamGuard Lite](https://img.shields.io/badge/⬇️_Install_ScamGuard_Lite-2196F3?style=for-the-badge)](https://www.mediafire.com/file/9pracvcp6ag6ynn/scamguard.user.js/file)

4. Upload the file in via browser
